# (계획) 노래 따라 흥얼거리기 — 이어받을 세션용 메모

> 상태: **1단계(진단) 만듦.** 우클릭 → 🧰 도구 → 🎵 Music 가사 읽기 테스트.
> `tools/ax-read.swift --music` (Music 만 허용, 가사 글자는 안 내보냄) + `src/main/music-lyrics.js` 의 `musicTest()`.
> 1.5초 간격으로 3번 읽어 `~/Library/Application Support/Live2D Desktop Mascot/music-read.txt` 에 저장 → 사용자가 보내 주면 2단계(판별 규칙·본 기능).

## 하고 싶은 것
Mac 의 **Music 앱(Apple Music)** 에서 노래가 재생되면, 캐릭터가 **지금 부르는 가사 줄을 말풍선으로** 띄워 흥얼거리는 것처럼 보이게 한다.
- **텍스트만.** 목소리로 따라 부르기는 하지 않음 (노래 합성 어려움, 원곡과 겹침, 보컬 음원 라이선스).
- Claude 를 쓰지 않음 (토큰 0). 기존 `mascot.say` 류 말풍선 + 몸짓 재사용.
- 설정 창에 **"노래 따라 흥얼거리기" 켜기/끄기**, 가능하면 **원문 / 번역 / 둘 다** 선택.
- 가사 칸이 닫혀 있거나 가사 없는 곡이면 `♪~` 정도만 띄우고 몸을 살랑살랑.

## 가사 얻는 방법 (합의)
**Music 앱 창의 가사 칸을 손쉬운 사용(Accessibility)으로 읽는다.**
- 외부 가사 사이트(LRCLIB 등)는 쓰지 않는 방향. 가사를 저장하지도 않음 (화면에 잠깐 띄우기만).
- AppleScript 의 `lyrics of current track` 은 가사 포함 로컬 파일만 되고 박자 정보가 없어 부적합.
- 기존 `tools/ax-read.swift` (같이 공부 모드가 Claude 앱 창을 읽는 도구)를 확장. 지금은 **Claude 앱만 읽도록 일부러 막혀 있음** → Music(`com.apple.Music`)만 추가 허용. 다른 앱은 계속 막을 것.
- Music 은 네이티브 앱이라 `AXManualAccessibility` 는 필요 없을 것.

## 사용자가 보여 준 화면 (2026-11)
- 가사가 Music 창 **오른쪽 칸**에 큰 글자 여러 줄로 표시. 지금 줄은 밝고 나머지는 회색, 지난 줄은 흐려짐. 일시정지면 전부 회색.
- 발음·번역을 켜면 한 줄이: **원문 줄 / 단어별 한글 발음(작은 글자) / 한국어 번역 줄** 로 나옴 → 단어 단위 요소일 수 있음. 셋을 구분해야 함.

## 확인해야 할 것 (실제 Mac 필요)
1. 가사 글자가 AX 트리에 나오는지.
2. **지금 줄** 판별: 밝기가 속성(AXSelected 등)으로 나오는지. 안 나오면 → Music 은 재생 중 지금 줄을 **항상 같은 높이로 스크롤**하므로 각 줄의 AXPosition/AXSize 로 그 높이에 있는 줄을 고른다.
3. 원문/발음/번역 구분 방법 (글자 크기·위치·순서).

## 진행 순서 (합의)
1. **진단 메뉴** "🎵 Music 가사 읽기 테스트" 추가 (`study.test` / `claude-read.txt` 와 같은 방식). 가사 칸을 열고 재생 중에 누르면 Music 창 구조(역할·위치·크기·속성)를 파일로 저장. **가사 글자 자체는 빼고**(글자 수 정도만) 구조만.
2. 사용자가 그 파일을 보내 주면 판별 규칙을 정해 본 기능 구현.
3. Music 상태는 1~2초마다 확인 (재생 중이고 기능이 켜져 있을 때만). 상태 확인 AppleScript 는 `applemusic-plugin/src/music.ts` 의 `SCRIPTS.status` 참고 — `application "Music" is running` 을 먼저 봐서 Music 을 켜 버리지 않게, 변수 이름에 `st` 같은 예약어 쓰지 말 것(-2741).

## 관련
- 스트림덱 Apple Music 플러그인: `applemusic-plugin/` (재생·이전·다음, 재생 중 앨범 표지). 이 기능과는 별개.
- 브리지 규격: `docs/STREAMDECK.md`. 나중에 스트림덱 버튼으로 흥얼거리기 켜기/끄기를 넣으려면 명령 추가.
