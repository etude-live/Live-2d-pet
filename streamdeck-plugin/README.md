# 스트림덱 플러그인 — Live2D 마스코트

Elgato **Stream Deck** 버튼으로 데스크톱 마스코트 앱을 조작해요.
포모도로, 말 걸기, 번역·다듬기, "이거 뭐야" 화면 질문, 표정 바꾸기, 사용량 보기 등.

- 필요한 것: **Mac** + **Stream Deck 앱 6.5 이상** + **마스코트 앱 2.0.0 이상**
- 버튼은 앱이 켜져 있을 때만 동작해요. 앱이 꺼져 있으면 모든 버튼이 흐려지고 "앱 꺼짐" 이라고 나와요. 앱을 켜면 3초 안에 저절로 다시 붙어요.

---

## 1. 설치 (처음 한 번)

1. 이 저장소의 [Releases 페이지](https://github.com/etude-live/Live-2d-pet/releases?q=streamdeck)에서 이름이 **`스트림덱 플러그인 v…`** 인 맨 위 릴리스를 열어요.
2. 아래 **Assets** 에서 **`Live2D-Mascot-StreamDeck-….streamDeckPlugin`** 파일을 눌러 받아요.
3. 받은 파일을 **더블클릭**하면 Stream Deck 앱이 "설치할까요?" 하고 물어요 → **설치**.
4. Stream Deck 앱 오른쪽 목록에 **"Live2D 마스코트"** 묶음이 생겨요.

> 마스코트 앱은 따로 켜 두세요. 플러그인은 앱이 열어 둔 연결(내 Mac 안에서만 쓰는 통로)로 앱에 명령을 보내요.

## 2. 버튼 놓기 (15키 추천 배치)

오른쪽 목록 **"Live2D 마스코트"** 에서 버튼을 끌어다 칸에 놓으면 돼요.

| | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| **1행** | 🍅 포모도로 | ⏭ 포모도로 건너뛰기 | 💬 말 걸기 | ⏹ 멈추기 | 🆕 새 대화 |
| **2행** | 📸 이거 뭐야 | 🌐 번역 | ✍️ 다듬기 | 💭 정해진 말 | 🔋 사용량 |
| **3행** | 😊 표정 | 😊 표정 | 😊 표정 | 📖 같이 공부 | 🤖 Claude 모드 |

- **😊 표정** 은 같은 버튼을 3칸에 놓고, 칸마다 다른 표정을 고르면 돼요 (아래 설명).
- **💭 정해진 말** 도 여러 칸에 놓고 칸마다 다른 말을 적을 수 있어요.

## 3. 버튼 설명

버튼 하나를 누르고 Stream Deck 앱 아래쪽에 나오는 칸이 **설정**이에요. 설정이 있는 버튼은 표에 적어 뒀어요.

| 버튼 | 누르면 | 버튼에 보이는 것 | 설정 |
|---|---|---|---|
| 🍅 **포모도로** | 시작 / 끝. **0.5초 이상 꾹 누르면 일시정지 / 다시** | 남은 시간 `24:59`. 집중 = 빨강, 휴식 = 초록, 일시정지 = 회색 | 집중·휴식·긴 휴식(분), 반복 횟수 (기본 25 / 5 / 15 / 4) |
| ⏭ **포모도로 건너뛰기** | 다음 단계로 (집중 ↔ 휴식) | | |
| 💬 **말 걸기** | 말 거는 입력칸 열기 / 닫기 | 캐릭터가 일하는 중이면 `…`. **승인을 기다리면 노랑·분홍으로 깜빡이며 "승인 대기"** | |
| ⏹ **멈추기** | 캐릭터가 하던 일 멈춤 | 성공하면 ✅ | |
| 🆕 **새 대화** | 새 대화 시작 (지난 대화는 기억으로 정리) | 성공하면 ✅ | |
| 📸 **이거 뭐야** | 화면을 찍어 캐릭터에게 질문 | 기다리는 동안 `…`, 끝나면 ✅ | 질문 (기본 "이 화면 설명해 줘"). **비워 두면** 묻지 않고 입력칸에 그림만 붙여 둬요 |
| 🌐 **번역** | **먼저 글을 복사(⌘C)** 하고 누르면, 번역해서 클립보드에 넣어 줘요 → ⌘V 로 붙여 넣기 | 기다리는 동안 `…`, 끝나면 ✅ | |
| ✍️ **다듬기** | 복사한 글을 다듬어 클립보드에 | 〃 | |
| 💭 **정해진 말** | 적어 둔 말을 캐릭터에게 건넴 | 성공하면 ✅ | 할 말 (기본 "오늘 할 일 정리해 줘") |
| 🔋 **사용량** | 새로고침 | Claude 5시간 한도 사용량 `37%` 과 배터리 그림. **80% 넘으면 빨강** | |
| 😊 **표정** | 캐릭터가 그 표정 + 대사. **한 번 더 누르면 원래 얼굴** | 지금 켜진 표정의 버튼은 **분홍 + 흰 테두리** | 표정(목록에서 고르기), 대사, 버튼 그림(웃음·부끄·슬픔…) |
| 📖 **같이 공부** | 같이 공부 모드 켜기 / 끄기 | `켜짐` (분홍 테두리) / `꺼짐` (회색) | |
| 🤖 **Claude 모드** | Claude 모드 켜기 / 끄기 (끄면 혼잣말 피규어) | `켜짐` / `꺼짐` | |

**표정 고르기:** 마스코트 앱을 켠 상태에서 표정 버튼의 설정을 열면, 지금 캐릭터 모델의 표정 목록이 나와요.
캐릭터 모델을 바꿨다면 설정 칸을 닫았다 다시 열어 주세요. 표정이 없는 모델이면 누를 때 **몸짓**을 하며 대사를 말해요.

### 버튼에 뜨는 표시

| 표시 | 뜻 | 어떻게 |
|---|---|---|
| 흐린 회색 + **앱 꺼짐** | 마스코트 앱이 꺼져 있음 | 앱을 켜면 3초 안에 저절로 돌아와요 |
| 주황 + **업데이트 필요** | 앱과 플러그인의 버전이 안 맞음 | 앱(2.0.0 이상)이나 플러그인을 최신으로 업데이트 |
| ⚠️ (노란 삼각형) | 명령이 실패함 | 버튼 제목에 이유가 잠깐 나와요 ↓ |
| **모드 꺼짐** | Claude 모드가 꺼져 있어서 못 함 | 🤖 버튼으로 켜기 |
| **바빠요** | 캐릭터가 다른 일을 하는 중 | 끝난 뒤 다시, 또는 ⏹ 멈추기 |
| **비어 있음** | 복사한 글이 없음 | 글을 먼저 ⌘C |
| **화면 권한** | Mac 화면 기록 권한이 없음 | 아래 "자주 묻는 것" |
| **표정 고르기** | 표정 버튼에 표정을 아직 안 고름 | 버튼 설정에서 고르기 |
| **응답 없음** | 앱이 답을 안 함 | 앱을 껐다 켜 보기 |

## 4. 업데이트

1. [Releases 페이지](https://github.com/etude-live/Live-2d-pet/releases?q=streamdeck)에서 더 새 `스트림덱 플러그인 v…` 를 받아요.
2. 더블클릭 → **설치**. 놓아 둔 버튼과 설정은 그대로 남아요.

플러그인 버전은 `메이저.마이너.패치` (예 `1.0.12`). 앱처럼, 앱과 주고받는 규격(protocol)이 바뀔 때만 메이저가 올라가요.

## 5. 자주 묻는 것

- **모든 버튼이 "앱 꺼짐" 이에요.** → 마스코트 앱이 켜져 있는지 확인하세요 (메뉴 막대에 아이콘). 앱을 켰는데도 그러면 앱을 한 번 껐다 켜 보세요.
- **📸 를 누르면 "화면 권한" 이 떠요.** → Mac **시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 기록** 에서 *Live2D Desktop Mascot* 을 켜고, 앱을 껐다 켜세요.
- **📖 같이 공부 버튼이 처음엔 켜짐/꺼짐이 안 보여요.** → 앱이 처음 연결 때 이 상태를 알려 주지 않아서, 한 번 누르거나 앱에서 바꾸면 그때부터 보여요.
- **버튼 제목을 내가 바꾸고 싶어요.** → 버튼 설정의 "제목" 칸에 적으면 그게 우선이에요 (그러면 남은 시간 같은 표시는 안 보여요).

## 개발자용

```
streamdeck-plugin/
├─ com.etude.mascot.sdPlugin/   ← 실제 플러그인 폴더 (manifest.json, 그림, 설정 화면 ui/, 빌드된 bin/)
├─ src/
│  ├─ plugin.ts                 ← Stream Deck SDK(@elgato/streamdeck) 와 연결하는 얇은 층
│  ├─ bridge/                   ← 앱 접속: bridge.json 읽기·3초마다 재접속·명령/결과·상태 (SDK 와 무관)
│  ├─ buttons/                  ← 버튼 13개의 로직 (누르면 무엇을 보내고, 상태를 어떻게 보여 줄지)
│  └─ icons.ts                  ← 버튼 그림(SVG)
├─ test/                        ← 가짜 앱(mock-app.ts) + 단위 테스트 + 진짜 bridge.js 접속 테스트 + e2e
└─ scripts/                     ← 아이콘 만들기, sdpi-components 받기, 버전 맞추기
```

```bash
cd streamdeck-plugin && npm ci
```

```bash
npm test            # 단위 테스트 (가짜 앱 + ../src/main/bridge.js 진짜 서버)
```

```bash
npm run build && npm run e2e   # 빌드된 bin/plugin.js 를 가짜 Stream Deck + 가짜 앱 사이에서 실행
```

```bash
npm run sdpi && npm run pack   # dist/com.etude.mascot.streamDeckPlugin
```

- 규격: [`docs/STREAMDECK.md`](../docs/STREAMDECK.md). 버튼 → 명령 대응은 `src/buttons/buttons.ts`.
- 앱 호환: 접속 직후 `welcome.protocol` 이 `1` 이 아니거나 앱 버전이 `2.0.0` 미만이면 모든 버튼에 "업데이트 필요" (`src/bridge/version.ts`).
- 실제 앱과 같은 명령을 터미널에서 보내 보기 (저장소 루트에서, 앱이 켜져 있을 때):
  `node scripts/bridge-send.js command '{"name":"pomodoro.toggle","args":{"work":25,"break":5,"long":15,"cycles":4}}'`
- 릴리스: `.github/workflows/streamdeck-plugin.yml` 이 `streamdeck-plugin/**` 가 바뀔 때만 돌아 `streamdeck-N` 태그로 올려요.
  앱 자동 업데이트가 `releases/latest` 를 보기 때문에 플러그인 릴리스는 **Latest 로 표시하지 않아요**.
